# افزونه فونت فارسی وردپرس

**PFont – Persian Font for WordPress**

افزونه **PFont** یک راهکار ساده و کاربردی برای تغییر فونت بخش‌های مختلف وردپرس و استفاده از فونت‌های فارسی در سایت و پیشخوان وردپرس است.

این افزونه با هدف بهبود تجربه کاربری سایت‌های فارسی‌زبان طراحی شده و امکان استفاده و مدیریت فونت‌های فارسی را بدون نیاز به ویرایش مستقیم فایل‌های قالب فراهم می‌کند.

## ✨ امکانات

- 🖋️ تغییر فونت پیشخوان وردپرس
- 🌐 امکان اعمال فونت در بخش کاربری سایت (Front-end)
- 🔤 پشتیبانی از فونت‌های فارسی و وب
- 📤 امکان بارگذاری فونت‌های دلخواه
- ⚙️ امکان انتخاب فونت از بخش تنظیمات افزونه
- 🎨 امکان تعیین `font-family` برای فونت‌های سفارشی
- 📏 امکان تعیین `font-weight` برای فونت‌های سفارشی
- 🧩 سازگاری با صفحه‌سازها و قالب‌های محبوب
- ⚡ بهینه‌سازی مصرف منابع
- 🔒 توجه به امنیت درخواست‌ها و عملیات مدیریتی
- 🔎 جست‌وجوی سریع فونت‌ها در لیست انتخاب فونت
- 🛠️ بدون نیاز به ویرایش فایل‌های قالب

## 📦 نصب

### نصب از پیشخوان وردپرس

1. وارد پیشخوان وردپرس شوید.
2. به مسیر **افزونه‌ها ← افزودن** بروید.
3. عبارت `PFont` را جست‌وجو کنید.
4. افزونه را نصب و فعال کنید.
5. وارد صفحه تنظیمات افزونه شوید و فونت موردنظر خود را انتخاب کنید.

### نصب دستی

1. آخرین نسخه افزونه را دریافت کنید.
2. فایل ZIP را در مسیر زیر بارگذاری و استخراج کنید:

```text
/wp-content/plugins/
```

3. افزونه را از بخش **افزونه‌ها** در وردپرس فعال کنید.
4. وارد صفحه تنظیمات PFont شوید.

## ⚙️ استفاده

پس از فعال‌سازی افزونه، می‌توانید از صفحه تنظیمات PFont فونت‌های موردنظر خود را برای بخش‌های مختلف انتخاب و تنظیم کنید.

در صورت استفاده از فونت سفارشی، امکان بارگذاری فونت و تعیین ویژگی‌های آن نیز وجود دارد.

> پیشنهاد می‌شود پس از نصب یا بروزرسانی افزونه، تنظیمات آن را بررسی و در صورت نیاز مجدداً ذخیره کنید.

## 🖥️ سازگاری

PFont برای استفاده در سایت‌های فارسی و محیط وردپرس طراحی شده است و با نسخه‌های جدید وردپرس و PHP سازگاری دارد.

### حداقل نیازمندی‌ها

- **WordPress:** 7.0+
- **PHP:** 7.4+
